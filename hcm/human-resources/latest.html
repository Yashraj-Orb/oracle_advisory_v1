Executive Summary

In the 26D release, the Human Resources category sees a wealth of new features and enhancements aimed at improving user experience and operational efficiency. The Benefits module introduces the Life Event Simulation Analyst, allowing users to simulate life events without making permanent changes, and the Benefits Administration Command Center, which centralizes benefits management tasks. The Help Desk module enhances user interaction with new Redwood interfaces and features like external document linking and a streamlined activities list. Additionally, the Human Resources module benefits from improved document management and enhanced navigation, with Redwood pages enabled by default for various functions. Customers should note the deprecation of the Process Automation task type in Journeys and prepare for required actions regarding baseline extractions for payroll interfaces.

What's New

  • Benefits introduces the Life Event Simulation Analyst, enabling users to run simulations for life events without making permanent changes, enhancing decision-making capabilities. (Life Event Simulation Analyst)
  • The Benefits Administration Command Center provides a unified workspace for managing benefits administration issues, featuring AI-generated summaries and insights. (Benefits Administration Command Center)
  • Help Desk now supports external document linking from requests, allowing agents to manage relevant information more efficiently. (Add Links to External Documents and Systems from Help Desk Requests)
  • The Redwood Experience is now enabled by default for various Employment pages, improving user access and experience across key HR functions. (Redwood Enabled by Default for Employment Pages in Update 26D; Redwood Enabled by Default for Employment Pages in Update 27A)
  • The Workforce Orchestration Command Center is introduced, helping leaders identify workforce conditions and prepare evidence-backed actions. (Workforce Orchestration Command Center)

What's Changed

  • The Actions list in Redwood Change Assignment now allows actions to be available even when their previous conditions are not met, improving user experience. (Enhanced Action List in Redwood Change Assignment)
  • Redwood person pages are now enabled by default, replacing responsive pages for various personal details, enhancing usability. (Redwood Enabled by Default for Person Pages)

Deprecations, Retirements and Replacements

  • The Process Automation task type is deprecated and will not be available after October 31, 2026, impacting journey setup pages. (Process Automation Task Type No Longer Available in Journeys Setup)
  • The Personal Information Assistant and Person Legislative Information supervisor agent templates are deprecated; users are encouraged to transition to the Person Data Assistant. (Personal Information Assistant and Person Legislative Information Agents Are Replaced by Person Data Assistant Agent)
  • The Representative Agent supervisor agent type is deprecated; users should use the Representative Assistant for enhanced capabilities. (Deprecating the Representative Agent (Supervisor Agent Type))
  • Human Resources: The existing Supervisor Agent template will no longer be supported. (Manage Journeys with AI Assistance)

Action Required

  • Organizations must perform a baseline extraction for payroll interfaces generated from the Global Payroll Interface template after applying this update to prevent full file extraction. (Perform a Baseline Extraction of Payroll Interfaces Generated from Global Payroll Interface Template; Perform a Baseline Extraction of Payroll Interface for ADP Global Payroll V2; Perform a Baseline Extraction of Payroll Interface for ADP Workforce Now)
  • Provision employee and administrator access to the Corporate Citizenship module and confirm navigation entry points before rollout. (Redwood Experience for Corporate Citizenship)
