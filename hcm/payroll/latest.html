Executive Summary

In the 26D release of Payroll, several enhancements and new features have been introduced to improve functionality and compliance. Key updates include the automation of SECURE 2.0 Act Section 603 catch-up eligibility, a new Tax Calculation Statement page for detailed tax insights, and enhancements to the Payroll Run Analyst AI Agent for better query resolution. Additionally, the Redwood user experience has been expanded across multiple modules, improving usability in tasks such as balance adjustments and payroll setup. Customers should note the required actions to transition from deprecated features, particularly regarding time elements upgraded to calculation components, which will be removed in the next release.

What's New

  • Payroll automates SECURE 2.0 Act Section 603 catch-up eligibility updates, improving compliance and reducing manual management. (SECURE 2.0 Act Section 603 Catch-Up Eligibility Update)
  • A new Tax Calculation Statement tab has been added to the Person Results page, providing detailed tax calculation information for payroll administrators. (Tax Calculation Statement Page: Federal Income Tax)
  • The Payroll Run Analyst AI Agent now supports natural-language queries about payroll tax deductions, enhancing efficiency in resolving tax-related questions. (Payroll Run Analyst AI Agent Enhanced to Support the Tax Calculation Statement (Federal Income Tax))
  • The Adjust Multiple Tax Balances task has been redesigned in Redwood, allowing for dynamic entry and review of adjustment values before processing. (Redwood Experience for Multiple Balance Adjustments)
  • The Tax Enforcement Level field has been introduced on Tax Withholding cards, enabling better tracking of annual limits for federal and state taxes. (Tax Enforcement Enhancement for Tax Withholding Cards)
  • Statutory tax rule management has been improved, allowing for easier creation and editing of overrides directly from the Statutory Rules UI. (USOPTE Statutory Tax Rules Enhancement)
  • Global Payroll now supports additional HR database items in rates-based salary calculations, enhancing real-time salary proposal capabilities. (Additional HR Database Items Enabled in Rates based Salary Calculations)
  • Redwood experience enhancements include new organization calculation cards and balance adjustment features, streamlining payroll management tasks. (Redwood Experience for Organization Calculation Cards; Redwood Experience for Balance Adjustment; Redwood Experience for Payroll Setup Pages)
  • New features in Payroll for Ireland include a Periodic Foreign Tax Credit entry option and enhancements to the Statutory Deduction Register for better reporting. (Periodic Foreign Tax Credit; Base Balances for Statutory Deduction Report)
  • Payroll for Canada introduces a new flow for annual tax credit indexing and enhancements to direct deposit file generation for RBC routing records. (Tax Credit and Total Claim Amount Indexing; Direct Deposit File Enhanced to Support RBC Routing Record)
  • New Payroll Activity Centers have been launched for various regions, allowing users to compare balance values across pay periods for improved payroll reviews. (Payroll Activity Center; Payroll Activity Center; Payroll Activity Center)

What's Changed

  • The Run Element Upgrade process now evaluates the maximum latest process date across payrolls to determine which elements to upgrade, reducing risks of incomplete upgrades. (Element Upgrade Process Configuration Date Enhancement)
  • UK Statutory Sick Pay processing will now utilize the published schedule in effect before a sickness absence to determine qualifying days, improving consistency in calculations. (Use Published Schedules to Determine UK Statutory Sick Pay Qualifying Days)

Deprecations, Retirements and Replacements

  • The feature for time elements upgraded to calculation cards using the Create Time Card Calculation Component flow will be removed in release 27D. Users must transition to the new Create time card elements for time entries feature to avoid disruption. (Important Actions and Considerations for Payroll)

Action Required

  • Customers must reimplement time elements upgraded to calculation components using the new Create Time Card Calculation Component process before release 27D. (Important Actions and Considerations for Payroll)
