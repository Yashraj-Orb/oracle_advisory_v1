Executive Summary

The 26D release for Workforce Management brings a host of enhancements across several modules, including Absence Management, Time and Labor, Workforce Health and Safety, and Workforce Scheduling. Notable improvements include the ability to record partial-day absence durations, enhanced visibility into compensatory plan balances, and new features for managing workday definitions in a guided Redwood experience. Additionally, the integration of organization calendar events into scheduling tools improves transparency and planning. Customers should be aware of required actions for setting up new features and the introduction of dedicated security roles for managing absences and entitlements.

What's New

  • Absence Management now supports using fast formulas to record partial-day absence durations, enhancing flexibility for absence types with days UOM. (Duration Formula Support for Absence Types With Days UOM and Elapsed Schedules)
  • The Compensatory Plan Balance page allows employees and managers to review compensatory plan balances as running totals for selected date ranges. (Review Compensatory Plan Balances as Running Totals)
  • A dedicated security role for Absences and Entitlements has been introduced, allowing for better alignment with organizational security policies. (Dedicated Security Role for Absences and Entitlements)
  • The Absences and Entitlements Redwood page now displays total funds available in the donation pool during balance transfers. (Donation Pool Fund Balance Available on Absences and Entitlements)
  • The Redwood Workday Definitions task allows users to create and manage workday definitions in a guided experience, improving usability. (Redwood Experience for Workday Definitions)
  • Calendar event enhancements on Redwood time cards provide clearer visibility into public holidays and default full-day event entries based on applicable schedules. (Enhancements for Calendar Events on Redwood Time Cards)
  • New metrics in the Incidents Real Time subject area enhance reporting on Environment Health and Safety, including counts for various incident types. (New Metrics in Incidents Real Time Subject Area)
  • The Team Schedule view now includes filter options for line managers and workers to focus on relevant organizational and event data. (Filter Options in Redwood Team Schedule)
  • The Shift Assignment Assistant helps Schedule Managers find the best worker for shifts using natural language queries, streamlining the assignment process. (Shift Assignment Assistant)

What's Changed

  • The Absence Planning page now sorts search results by name rather than absence status, improving clarity and usability. (Default Sorting by Name in Absence Planning)
  • The integration of absence management with Redwood time cards allows for clearer visibility into absence approvals and their statuses, enhancing overall record accuracy. (Enhancements for Absence Integration on Redwood Time Cards)
  • Minimum staffing levels can now guide schedule generation, prioritizing assignments that help meet staffing targets, improving staffing coverage. (Prioritize Minimum Staffing in Schedule Generation)

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Assign the Absence and Entitlement Management Duty role to a custom role to utilize the new dedicated security role for Absences and Entitlements. (Dedicated Security Role for Absences and Entitlements)
  • Enable the profile option for the Absences Leave Agreement experience to access the enhanced Leave Agreements page. (Enhanced Leave Agreements Page)
  • Define full day public holidays and other calendar events to take advantage of the enhancements for calendar events on Redwood time cards. (Enhancements for Calendar Events on Redwood Time Cards)
  • Configure minimum staffing in the staffing grid to utilize the new prioritization feature for schedule generation. (Prioritize Minimum Staffing in Schedule Generation)
