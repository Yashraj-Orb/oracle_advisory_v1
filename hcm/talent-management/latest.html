Executive Summary

The 26D release for Talent Management brings a host of new features and enhancements across various modules, including Compensation, Dynamic Skills, Learning and Development, Opportunity Marketplace, and Recruiting. Major highlights include the introduction of AI-driven insights for Talent Review, which allows managers to calibrate performance ratings and view talent profiles directly within the review context. Additionally, enhancements in goal management streamline the assignment and updating of goals, while new capabilities in recruiting improve candidate engagement and application processes. Customers should be aware of required actions for enabling new features and configuring settings to maximize the benefits of these updates.

What's New

  • Compensation introduces the ability to duplicate salary basis configurations, simplifying setup processes. (Duplicate a Salary Basis)
  • Dynamic Skills enhances skill recommendations by incorporating job context, improving relevance for users with limited skill data. (Enhanced Skill Recommendations Based on Nonskill Talent Profile Attributes)
  • Learning and Development adds the Agentic Course Player, allowing learners to navigate self-paced courses with guided content and assessments. (Agentic Course Player)
  • Opportunity Marketplace now automates candidate referral creation via email, streamlining the referral process for employees. (Automate Candidate Referral Creation)
  • Talent Management enhances goal management with features like AI-assisted goal creation and the ability to assign goals directly from the Team Activity Center. (Include Document Tool in Goal Creation AI Agent; Manager Assigns Performance and Development Goals in Team Activity Center)
  • Performance Management improves the review process with auto-save functionality for updates made during Talent Review meetings. (Auto-Save Status Updates for Talent Review)
  • Profile Management introduces badging in profiles, allowing visual representation of achievements within the Honors and Awards section. (Redwood: Badges in Profiles)
  • Succession Management updates the Succession Planning Guide agent to support natural-language requests for finding potential successors. (Updated Succession Planning Agent to Find Best Matching Candidates for Succession Plans)

What's Changed

  • The check-ins experience has been simplified, allowing for easier template selection and enriched discussion topics. (Simplify Check-Ins Experience)
  • The Team Sync Check-Ins and Summary features now allow customization and improved summarization of employee-manager interactions. (Enhancements to Team Sync Check-Ins and Team Sync Summary)

Deprecations, Retirements and Replacements

  • Learning and Development: The original offering is deprecated after migration, but completed and in-progress assignments remain associated with it. (Bulk migrate self-paced offerings using a REST API)
  • Learning and Development: BI Cloud Connector (BICC) will no longer be supported after release 27A, replaced by Learning Catalog and Assignments Data Extraction starting from release 26C. (Important Actions and Considerations for Learning)
  • Recruiting: Oracle Digital Assistant Fusion Apps templates for Recruiting will be deprecated in November 2026, transitioning to Career Coach. (Transition From Digital Assistant on Recruiting Sites)

Action Required

  • Enable the Goal Level Approval Enabled profile option to utilize new goal management features. (Support Goal Level Approvals in the Employee Goals Assistant Agent)
  • Configure the Control Time-Based Autosave Counter on the Provide Requested Feedback Page property to benefit from autosave features in Performance Management. (Redwood: Time-Based Autosave for Providing Requested Feedback)
  • Set the Enable Security Console External Application Integration profile option to Yes for using the Manager Coaching Workspace. (Identify Coaching Insights for your Team Using Manager Coaching Workspace)
