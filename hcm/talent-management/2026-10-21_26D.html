Covers: Oracle Me Employee Experience 26D
Generated: 2026-10-21 · Source: Oracle Cloud Readiness

Executive Summary

The latest release of Oracle Me Employee Experience (26D) brings a host of new features and enhancements aimed at improving employee engagement and communication. Key updates in the HCM Communicate module include the ability to create campaigns using Oracle HCM questionnaires, designate employee events as private, and manage post-event resources effectively. Additionally, employees can now receive targeted communications through Microsoft Teams and Slack, enhancing the reach of organizational messages. The Grow module also sees improvements with enhanced skill recommendations based on job context, further supporting employee development. Customers should be aware of the setup requirements for some new features to ensure optimal use.

What's New

  • Oracle Communicate now allows the creation of campaigns that collect feedback using Oracle HCM questionnaires, enabling tracking of participation and responses. (Use Questionnaires in Oracle Communicate Campaigns)
  • Event managers can create and share post-event resources in a central location, including files and URLs for easy access by registrants. (Manage Post-Event Resources for Employee Events)
  • Campaign messages can now be sent directly to selected employees through Microsoft Teams and Slack, allowing for more targeted communication. (Reach Employees Directly Through Microsoft Teams and Slack)
  • You can now include nonworkers in campaign audiences using HCM lists and eligibility profiles, broadening communication reach. (Include Nonworkers in Campaign Audiences)
  • Workers can now use the Grow Coach Workspace and Ask Oracle in Grow to receive prioritized guidance for skills and learning activities. (Use Grow Coach Workspace and Ask Oracle in Grow to receive learning guidance)

What's Changed

  • The event creation workflow now includes an Audience step for private events, improving clarity between public and private events. (Separate Event Audience and Promotions)
  • The Manage Email Templates page has been redesigned in Setup and Maintenance to provide a consistent Redwood experience. (Manage Email Templates with the Redwood Experience)
  • The Skill Similarity recommender has been enhanced to provide more relevant skill recommendations based on additional job and position context. (Enhanced Skill Recommendations Based on Nonskill Talent Profile Attributes)

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Set the site profile value to Y for ORA_HCM_COMM_EVT_ATTACH_EXTS to enable post-event resource management. (Manage Post-Event Resources for Employee Events)
  • Configure Microsoft Teams or Slack integration for Oracle Communicate to utilize direct messaging features. (Reach Employees Directly Through Microsoft Teams and Slack)
  • Enable ORA_HCO_WORKERS_ASSIGNMENT_STATUS and ORA_HCO_WORKERS_ASSIGNMENT_TYPE profile options to include nonworkers in campaign audiences. (Include Nonworkers in Campaign Audiences)
  • Assign the Access Grow Coach Workspace function privilege to employees to allow access to the Grow Coach Workspace. (Use Grow Coach Workspace and Ask Oracle in Grow to receive learning guidance)
