Executive Summary

In the 26D release for Common Technologies and User Experience, several key updates enhance user interaction and AI functionality. Users can now record issues directly on Redwood pages, while administrators gain the ability to manage AI unit budgets and monitor consumption effectively. The AI Agent Studio introduces multiple new features, including integration with CI/CD processes and the ability to create autonomous outcomes using Oracle Fusion Claw. Additionally, multifactor authentication is now required for users in new environment families, necessitating prompt enrollment. Customers should also be aware of the deprecation of certain Business Intelligence View Objects and the upcoming discontinuation of Oracle Digital Assistant skills.

What's New

  • Users can now record issues on Redwood pages using the 'Record Issue' option in the Settings and Actions menu, requiring specific administrator permissions. (Record issues on Redwood pages)
  • Administrators can manage AI unit budgets and monitor consumption from a single workspace in AI Agent Studio, including setting budgets and configuring alerts. (Manage AI unit budget, consumption, and controls)
  • AI Agent Studio now integrates with CI/CD processes, allowing for controlled application and workflow deployments. (Integrate AI Agent Studio applications and workflows with CI/CD)
  • The AI Agent Studio Testing and Lifecycle Automation Suite (ATLAS) supports regression testing for workflows, enabling detailed test reporting. (Test and validate AI Agent Studio workflows with ATLAS)
  • Oracle Fusion Claw is introduced for creating autonomous outcomes through AI-driven automation, allowing users to define outcomes in natural language. (Use Oracle Fusion Claw to create autonomous outcomes with agentic applications)
  • Users can add instruction guardrails to large language model nodes in workflows to enhance response reliability and safety. (Add instruction guardrails to LLM nodes)
  • AI Agent Studio introduces an AI Guidance node for linking insights to business objects securely. (Configure an AI guidance node in a workflow)
  • Contextual announcement banners can now be enabled on Redwood pages to display important information, configurable through Visual Builder Studio. (Contextual announcement banner on Redwood pages)
  • The Redwood appearance editor allows overriding accessibility checks for custom colors, enabling brand colors as primary colors for themes. (Redwood appearance editor: Override accessibility checks and use as primary color)

What's Changed

  • The Oracle Fusion Cloud Applications Sign In page has been updated to display different interfaces based on federated or non-federated Single Sign-On, particularly for OCI IAM users. (Changes in Oracle Fusion Cloud Applications Sign In page)

Deprecations, Retirements and Replacements

  • Certain Business Intelligence View Objects (BIVOs) are deprecated and no longer available for extraction using BI Cloud Connector, requiring users to update their BICC tasks accordingly. (Deprecated and new BI view objects in Oracle BI Cloud Connector)
  • Oracle Digital Assistant skills for Fusion Applications will be discontinued on November 21, 2026, necessitating migration to AI Agent Studio. (IMPORTANT Actions and Considerations)

Action Required

  • Users must enroll in multifactor authentication (MFA) when signing in to Oracle Fusion Cloud Applications if they are part of new environment families created from 25D onwards. (Multifactor authentication (MFA))
  • Ensure security administrator assigns roles with 'Record and View Issue' privilege and other related privileges for issue recording on Redwood pages. (Record issues on Redwood pages)
  • Access AI Agent Studio to manage budgets and configure new features introduced in this release. (Manage AI unit budget, consumption, and controls; Integrate AI Agent Studio applications and workflows with CI/CD; Test and validate AI Agent Studio workflows with ATLAS)
  • Edit Page in Visual Builder Studio to enable contextual announcement banners on Redwood pages. (Contextual announcement banner on Redwood pages)
  • Create or enter a sandbox to utilize the new features in the Redwood appearance editor. (Redwood appearance editor: Override accessibility checks and use as primary color)
