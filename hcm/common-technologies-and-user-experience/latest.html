Executive Summary

In the latest release (26D) for Common Technologies and User Experience, significant enhancements have been made across various modules. Users can now record issues directly on Redwood pages, which aids in troubleshooting and bug resolution. AI Agent Studio has seen the introduction of features for managing AI unit budgets, integrating CI/CD processes, and creating autonomous outcomes with Oracle Fusion Claw. Additionally, users can create and manage Ask Oracle plugins, extending the platform's capabilities. These updates require some setup, particularly for the new recording features and contextual announcement banners on Redwood pages, ensuring that users are equipped to leverage these enhancements effectively.

What's New

  • Users can now record issues on Redwood pages using the Record Issue feature, which helps support teams with troubleshooting. (Record issues on Redwood pages)
  • AI Agent Studio introduces management of AI unit budgets, allowing administrators to set budgets and monitor consumption effectively. (Manage AI unit budget, consumption, and controls)
  • The ability to configure models and manage their lifecycle in AI Agent Studio provides users with enhanced control over large language models. (Configure models and manage model lifecycle)
  • AI Agent Studio now supports integration with CI/CD processes, improving deployment management through a controlled development lifecycle. (Integrate AI Agent Studio applications and workflows with CI/CD)
  • Oracle Fusion Claw allows users to create autonomous outcomes through AI-driven automation, defining outcomes in natural language. (Use Oracle Fusion Claw to create autonomous outcomes with agentic applications)
  • Users can create and manage Ask Oracle plugins in AI Agent Studio, extending its capabilities with specialized functionalities. (Create and manage Ask Oracle plugins)
  • Contextual announcement banners can be enabled on Redwood pages to display important information, configurable via Visual Builder Studio. (Contextual announcement banner on Redwood pages)
  • The Redwood appearance editor now allows overriding accessibility checks for custom colors, enabling brand colors as primary themes. (Redwood appearance editor: Override accessibility checks and use as primary color)

What's Changed

  • The Redwood appearance editor has been enhanced to allow users to override accessibility checks for custom colors, which was not possible before. (Redwood appearance editor: Override accessibility checks and use as primary color)
