HCM · Strategic Workforce Planning: Release digest

Covers: Enterprise Performance Management 26.09
Generated: 2026-10-20 · Source: Oracle Cloud Readiness

Executive Summary

In the 26.09 release of Enterprise Performance Management, several modules have received substantial updates, particularly in AI integration and user interface enhancements. The Financial Consolidation and Close module introduces the Tax Journal Assistant, which leverages generative AI to facilitate journal creation, enhancing efficiency in tax reporting. Additionally, predefined dashboards in Strategic Workforce Planning and other modules have been automatically upgraded to Dashboard 2.0, providing a more polished user experience. Customers should note that the original PCM Agent will be deprecated in the upcoming October update, necessitating a transition to the Enhanced PCM Agent for continued support.

What's New

  • The Tax Journal Assistant for Users in Tax Reporting helps streamline journal creation from TAR Journal Posting data, allowing natural language input for data extraction. (EPM Assistants: Tax Journal Assistant for Users)
  • The Consolidation Assistant in Financial Consolidation and Close assists Service Administrators in diagnosing system issues and recommending resolutions using generative AI. (Consolidation Assistant)
  • Predefined dashboards in Strategic Workforce Planning and other Planning Modules have been automatically upgraded to Dashboard 2.0, enhancing UI and feature utilization. (Predefined Dashboards in Modules, Sales Planning and Strategic Workforce Planning Automatically Upgraded to Dashboard 2.0)
  • Generative AI support is now available in OC2 and OC3 realms, enabling customers to utilize AI features in these regions. (Generative AI Support Available in OC2 and OC3 Realm)
  • New Consolidation Settings in Financial Consolidation and Close allow administrators to define limits on concurrent consolidations and translations, improving performance management. (Consolidation Settings for Concurrent Consolidations and Translations and Queued Jobs)
  • The new runApplicationDiagnostics EPM Automate command allows users to create an Application Diagnostics report to validate compliance with best practices. (New runApplicationDiagnostics EPM Automate Command)
  • The Consolidation Approvals Assistant provides a workflow for managing approval unit statuses, packaged as a downloadable ZIP file for setup. (EPM Assistants: Consolidation Approvals Assistant)
  • Generative AI can now be used in Data Discovery to summarize and format output from Notes and trace files into an HTML dashboard, streamlining data analysis. (Generative AI in Data Discovery)

What's Changed

  • The process for resubmitting enriched requests has changed, allowing users to resubmit requests even if they lack direct access to the changes made during enrichment. (Relaxed Permission Check During Resubmit of Enriched Request)
  • Audit data availability through EPM Automate and REST APIs has been updated to reflect a new retention period, allowing reports for application role assignments for up to 14 days and granular role assignments for up to 120 days. (Audit Data Availability Through EPM Automate and REST APIs)
  • The First Name field for creating and updating users in Cloud EPM is now optional, enhancing user administration flexibility. (First Name Is Optional for EPM Users)

Deprecations, Retirements and Replacements

  • The original PCM Agent will no longer be available starting October 2023; users are encouraged to transition to the Enhanced PCM Agent for continued support. (The Enhanced PCM Agent Now Supports Trace)

Action Required

  • Update existing Cloud EPM connections to specify an Access Token URI for OAuth 2.0 authentication before use. (Access Token URI for OAuth 2.0 Cloud EPM Connections)
  • Enable Generative AI from Application Settings to utilize the new AI features in the Tax Journal Assistant and Consolidation Assistant. (Consolidation Assistant; EPM Assistants: Tax Journal Assistant for Users)
  • Download and extract the ZIP file for the Consolidation Approvals Assistant, then import the JSON files into AI Agent Studio and publish them. (EPM Assistants: Consolidation Approvals Assistant)
  • Specify positive numbers for maximum values in Consolidation Settings to manage job execution effectively. (Consolidation Settings for Concurrent Consolidations and Translations and Queued Jobs)
  • Configure default property groups for viewpoints to control which properties are displayed initially for selected nodes. (Default Property Groups for Viewpoints)
  • Register integrations in Enterprise Data Management and assign the Integrations - Manage role to users to execute and monitor Oracle Integration Cloud processes. (Execute and Monitor Oracle Integration Cloud Processes)
  • Enable the Include Management Hierarchy parameter in the policy inspector for ownership approval policies. (Include Management Hierarchy for Ownership Approval Policies)
