Executive Summary

In the 26D release of Project Management, several significant enhancements have been made, particularly through the introduction of AI-powered workspaces for project planning and billing operations. The Project Planning Workspace facilitates project initiation and budget planning, while the Billing Operations Workspace streamlines billing readiness and dispute resolution. Additionally, new features enhance financial oversight and project cost management. Customers are required to opt in to these new features to enable them, and they should review the New Features work area for additional setup requirements. Notably, Oracle Digital Assistant templates will be desupported in 2026, prompting users to transition to Oracle AI Agent Studio.

What's New

  • The Project Planning Workspace introduces AI capabilities for project initiation and budget planning, enabling users to estimate opportunity costs and generate proposals. (Project Planning Workspace for project initiation and budget planning)
  • The Billing Operations Workspace provides a unified experience for billing readiness and dispute resolution, utilizing automated actions to streamline billing processes. (Billing Operations Workspace for billing readiness and dispute resolution)
  • Project Financial Control Agents enhance financial oversight with insights into project costs and billing exceptions through conversational interactions. (Project Financial Control Agents)
  • The feature for ingesting contract documents using AI allows batch processing and classification of existing contracts, reducing manual effort. (Ingest Contract Documents Using AI)
  • Payroll encumbrance distribution to Projects tracks payroll-generated encumbrances as project labor commitments, enhancing budget visibility. (Payroll encumbrance distribution to Projects)
  • Task output quantities can now be used to measure and track work progress, allowing project managers to analyze productivity against planned benchmarks. (Track progress with task output quantities)
  • Additional accounting sources for non-project labor costs improve the accuracy of accounting segment derivation by using more detailed worker attributes. (Additional accounting sources for non-project labor costs)
  • Labor schedule management pages have been updated for improved user experience, featuring enhanced search and filtering capabilities. (Updated labor schedule management pages)

What's Changed

  • Deletion of project intercompany and interproject invoices in Payables is now restricted when corresponding invoices are in Accepted status, preventing data inconsistencies. (Prevent deletion of project intercompany and interproject invoices pending completion in Payables)
  • This update includes several bug fixes affecting application behavior, such as the removal of Basic Authentication for DocuSign and support for pending workers in employment contracts. (Selected Contracts Bug Fixes in This Update)

Deprecations, Retirements and Replacements

  • Oracle Digital Assistant (ODA) Fusion Apps templates will be desupported on November 21, 2026, with a recommendation to transition to Oracle AI Agent Studio. (IMPORTANT Actions and Considerations)
