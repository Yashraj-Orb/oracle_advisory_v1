Executive Summary

The 24C and 26D releases for Risk Management bring a host of new features and enhancements across Financial Reporting Compliance and both Classic and Redwood Risk Management modules. Key improvements include enhanced question responses for surveys, new job history dimensions for tracking advanced controls, and a revamped security framework that allows better record access management. Additionally, users can now manage internal control records and access certification campaigns more efficiently. There are no deprecations, but users should be aware of required actions to fully leverage these new capabilities.

What's New

  • Financial Reporting Compliance introduces enhanced question responses for surveys, allowing detailed feedback for better analysis and decision-making. (Enhanced Question Responses)
  • New job history dimensions for tracking advanced controls have been added, enabling reporting on access and transaction job history. (New Advanced Controls Job History Dimensions)
  • Risk Management (Classic) now includes two pre-built reports: Access Global Conditions Report and Access Entitlements Report for reviewing access conditions and entitlements. (Access Global Conditions and Access Entitlements reports)
  • Risk Management (Redwood) features a new secured record access framework, enhancing control over record creation and access management. (Risk Management secured record access framework)
  • The Risk Cloud Daily Digest feature consolidates relevant activities into a daily email for authorized users, improving communication without overwhelming inboxes. (Receive the Risk Cloud Daily Digest)
  • Participant Groups can now be created for easier management of user collections across records, supporting mass actions for updates. (Participant Groups and record access management)
  • New features for managing algorithms include defining reusable filters and user-defined access paths, enhancing control over access management. (Define reusable Algorithm Filters; Define reusable User-Defined Access Paths)
  • Internal Control record management allows users to centralize and manage internal controls, including creating controls from templates and running reports. (Internal Control record management)
  • Access Certification campaign management enables users to oversee campaigns for user role access retention, including task monitoring and reassignment. (Access Certification campaign management)

What's Changed

  • Business object attributes and names in Risk Management (Classic) have been updated for better alignment with application data, requiring users to run the Transaction Data Source Synchronization job and review existing controls. (Business object changes)

Deprecations, Retirements and Replacements

  • The Sensitive Data Access Audit will be deprecated as user read access to sensitive pages will no longer be tracked in future releases. (Business object changes)

Action Required

  • Users must run the Report Synchronization job to utilize new job history dimensions for advanced controls. (New Advanced Controls Job History Dimensions)
  • To leverage the new secured record access framework, assign the appropriate roles to users, including Risk Administrator and Risk User roles. (Risk Management secured record access framework)
  • Enable the Preference for Advanced Access Request configuration and assign necessary privileges to relevant users. (Submit and manage Advanced Access Request)
