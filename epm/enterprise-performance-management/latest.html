Executive Summary

In the 26.10 release of Enterprise Performance Management, several new AI features have been introduced, such as the Enhanced PCM Agent for performance analysis and the Consolidation Process Assistant for streamlined data integrations. Enhancements also include improved user experiences with Redwood styling across applications and new functionalities in EPM Automate and REST APIs. Customers should be aware of the deprecation of JDK 17 support in EPM Automate, which will require an upgrade to JDK 21 by January 2027. Additionally, the new Balance Loads card and various reporting enhancements aim to improve operational efficiency and data analysis capabilities.

What's New

  • The Enhanced PCM Agent now includes performance analysis capabilities for completed calculation jobs, helping identify bottlenecks in Enterprise Profitability and Cost Management. (PCM Agent Calculation Performance Analysis Capabilities)
  • A new Consolidation Process Assistant is available, enabling users to execute data integrations and consolidations through natural language interactions in Financial Consolidation and Close. (EPM Assistants: Consolidation Process Assistant)
  • The new listUsers EPM Automate command allows for creating a JSON report of user information and roles, aiding in audits. (New listUsers EPM Automate Command and REST API)
  • Data Exchange now supports OAuth 2.0 for secure connections to NetSuite, enhancing security for Financial Consolidation and Close. (Support for OAuth 2.0 for NetSuite Connections)
  • A new chapter titled 'Working with AI' has been added to business process guides, detailing available AI features and usage documentation. (New "Working with AI" Chapter)
  • The Reporting Agent now assists in investigating data patterns by generating a ranked analysis grid, enhancing data analysis across modules. (Reporting Agent Causal Analysis)
  • The Transactions tab in Account Reconciliation now displays total transaction amounts based on current search criteria, improving productivity during audits. (Display of Transaction Sum in the Transactions Tab of Transaction Matching)
  • Service Administrators can configure automatic purging of balance load information after a specified number of days, maintaining application performance. (Ability to Automatically Purge Balance Load Information)
  • A new REST API for retrieving translation diagnostic information has been introduced in Tax Reporting, enabling automated investigation of translation issues. (Diagnosis of Translation Issues Using a REST API)
  • The new Period Movement Variance insight type in Tax Reporting detects significant variances between periods, allowing for better monitoring of tax-related accounts. (IPM Insights: New Period Movement Variance Insight Type)

What's Changed

  • The Export to CSV option in Access Control now supports exporting all group types, including EPM, IDCS, and PREDEFINED groups, enhancing data management capabilities. (Support of All Group Types in Exported Group Listing in Access Control)
  • The Home page and global header experience have been enhanced with Redwood styling, improving accessibility and navigation across multiple modules. (Enhanced Home Page and Global Header Experience; Enhanced Home Page and Global Header Experience; Enhanced Home Page and Global Header Experience)
  • Insertion points in the consolidation sequence now allow the use of attribute functions in on-demand rules, enabling more flexible calculation logic. (Insertion Point Rules Opend up to Allow Attribute Dimension Functions)

Deprecations, Retirements and Replacements

  • Support for JDK 17 in EPM Automate on Linux/Unix will be deprecated in the January 2027 update, requiring an upgrade to JDK 21 by then. (Java 21 support for EPM Automate on Linux/Unix)
  • The original PCM Agent and PCM Agent Performance Assistant will no longer be available starting in the November update (26.11). (PCM Agent Calculation Performance Analysis Capabilities)

Action Required

  • Service Administrators should upgrade to JDK 21 before the January 2027 update to maintain EPM Automate functionality. (Java 21 support for EPM Automate on Linux/Unix)
  • Enable the new Consolidation Setting called 'Data Retrieval Diagnosis' for performance analysis in Financial Consolidation and Close. (EPM Assistants: Consolidation Process Assistant; EPM Assistants: Consolidation Journals Assistant)
  • Configure the number of days for automatic purging of balance load information in Account Reconciliation to optimize performance. (Ability to Automatically Purge Balance Load Information)
  • Configure period movement variance insights in IPM Configurator to utilize the new insight type in Tax Reporting. (IPM Insights: New Period Movement Variance Insight Type)
