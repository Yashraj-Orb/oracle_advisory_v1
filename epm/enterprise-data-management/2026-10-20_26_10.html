Executive Summary

The 26.10 release of Enterprise Data Management brings significant enhancements, including a new chapter on AI capabilities in business process guides and improved export functionality for access control, allowing for the export of all group types. Additionally, a new listUsers command and REST API have been introduced, facilitating user information reporting. Customers are required to upgrade to Cloud EPM 26.08 or later by January 2027 to maintain access to Generative AI features, and earlier versions of EPM Automate will not be compatible with future updates. Support for JDK 17 will also be deprecated in January 2027, necessitating an upgrade to JDK 21 for EPM Automate on Linux/Unix systems.

What's New

  • Enterprise Data Management adds a new chapter titled 'Working with AI' in business process guides, enhancing user understanding of AI features. (New "Working with AI" Chapter)
  • A new listUsers command and corresponding REST API are now available, allowing users to generate a JSON report of user information and role assignments. (New listUsers EPM Automate Command and REST API)
  • The Export to CSV option in Access Control now supports exporting all group types, aiding in security reviews and access audits. (Support of All Group Types in Exported Group Listing in Access Control)

What's Changed

  • The copyToSFTP and copyFromSFTP commands now support an uploaded private key file for enhanced security when invoked from Groovy scripts. (Support for Uploaded Private Key in copyToSFTP and copyFromSFTP Commands Invoked From Groovy Scripts)

Deprecations, Retirements and Replacements

  • Support for JDK 17 will be deprecated in January 2027; users must upgrade to JDK 21 for EPM Automate on Linux/Unix systems. (Java 21 support for EPM Automate on Linux/Unix)
  • Support for user names prefixed with the Cloud Account name will be removed in November 2026. (IMPORTANT Actions and Considerations)

Action Required

  • Upgrade EPM Automate to version 26.09 or later to ensure compatibility with future environments. (IMPORTANT Actions and Considerations)
  • Run the EPM Automate encrypt command to generate a new.epw file as part of the upgrade process. (IMPORTANT Actions and Considerations)
  • Upgrade environments to Cloud EPM 26.08 or later by January 2027 to maintain access to Generative AI features. (IMPORTANT Actions and Considerations)
