Executive Summary

In the 26D release of the Common Technologies and User Experience category, several new features and enhancements have been introduced across various modules. Users can now record issues directly on Redwood pages, facilitating better support for troubleshooting. AI Agent Studio has expanded its capabilities, allowing administrators to manage AI unit budgets, integrate CI/CD processes, and implement testing automation through ATLAS. Additionally, the sign-in page has been updated for environments using OCI Identity and Access Management, which will affect user experience based on their SSO configuration. A crucial action for users is to enroll in multifactor authentication if they are part of new environment families created from 25D onwards, ensuring enhanced security. Furthermore, certain Business Intelligence View Objects are deprecated, necessitating updates to BI Cloud Connector tasks.

What's New

  • Users can now record issues on Redwood pages using the Record Issue feature, enhancing help desk efficiency. (Record issues on Redwood pages)
  • Administrators can manage AI unit budgets and monitor consumption from AI Agent Studio, including setting alerts for budget limits. (Manage AI unit budget, consumption, and controls)
  • AI Agent Studio supports integration with CI/CD processes, improving deployment consistency and reducing manual publishing reliance. (Integrate AI Agent Studio applications and workflows with CI/CD)
  • The AI Agent Studio Testing and Lifecycle Automation Suite (ATLAS) now provides regression testing capabilities for workflows and applications. (Test and validate AI Agent Studio workflows with ATLAS)
  • Oracle Fusion Claw is introduced for creating autonomous outcomes through AI-driven automation, allowing users to define outcomes in natural language. (Use Oracle Fusion Claw to create autonomous outcomes with agentic applications)
  • Users can add instruction guardrails to LLM nodes in workflows to enhance safety and governance of AI responses. (Add instruction guardrails to LLM nodes)
  • AI Agent Studio introduces an AI Guidance node that connects workflow guidance to business objects for insights and recommendations. (Configure an AI guidance node in a workflow)
  • Contextual announcement banners can now be enabled on Redwood pages to display important information and compliance messaging. (Contextual announcement banner on Redwood pages)
  • The Redwood appearance editor allows overriding accessibility checks for custom colors, enabling brand colors as primary theme colors. (Redwood appearance editor: Override accessibility checks and use as primary color)

What's Changed

  • The sign-in page for Oracle Fusion Cloud Applications has been updated to reflect different designs based on SSO configurations and OCI IAM usage. (Changes in Oracle Fusion Cloud Applications Sign In page)
  • AI Agent Studio now allows users to select specific large language models (LLMs) for workflows, with the Balanced category replacing the former Premium category. (Configure models and manage model lifecycle)

Deprecations, Retirements and Replacements

  • Certain Business Intelligence View Objects (BIVOs) are deprecated and no longer available for extraction using BI Cloud Connector. Users should review the Deprecated and New BI View Objects spreadsheets to update their BICC tasks accordingly. (Deprecated and new BI view objects in Oracle BI Cloud Connector)
  • Oracle Digital Assistant skills for Fusion Applications will be discontinued on November 21, 2026, requiring customers to develop migration plans. (IMPORTANT Actions and Considerations)

Action Required

  • Users must enroll in multifactor authentication (MFA) when signing in to Oracle Fusion Cloud Applications if they are part of new environment families created from 25D onwards. (Multifactor authentication (MFA))
  • Ensure security administrators assign roles with the necessary privileges for new features, including Record and View Issue, Set Issue Recording Advanced Options, and View Version Information. (Record issues on Redwood pages)
  • Ensure access to AI Agent Studio for utilizing new features related to AI management and testing. (Manage AI unit budget, consumption, and controls; Integrate AI Agent Studio applications and workflows with CI/CD; Test and validate AI Agent Studio workflows with ATLAS)
