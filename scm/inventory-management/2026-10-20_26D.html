Covers: Inventory Management 26D
Generated: 2026-10-20 · Source: Oracle Cloud Readiness

Executive Summary

Release 26D for Inventory Management brings a host of new capabilities aimed at improving operational efficiency and flexibility. Key enhancements include the ability to perform intra-organizational material transfers from Self Service Procurement, advanced mobile functionalities for cycle counts, and improved integration for transfer orders routed through Order Management. Clients must complete pre-update tasks and can opt in to several new features that may be disabled by default. Additionally, the release includes enhancements to electronic records and signatures for material transactions, further supporting compliance and audit trails.

What's New

  • Supply Chain Orchestration now enables intra-organizational material transfers for supply requests from Self Service Procurement, improving fulfillment flexibility and inventory utilization. (Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement)
  • Oracle Supply Chain Orchestration captures inventory on hand striping attributes for manual transfer supply requests, ensuring accurate inventory characteristics during transfer order creation. (Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration)
  • The Inventory Task Allocation Assistant AI agent can automatically assign receipt delivery tasks to robotic material handling equipment, optimizing resource allocation in warehouse operations. (Inventory Task Allocation Assistant - Assign tasks to robotic material handling equipment)
  • The LPN Packing Advisor AI agent recommends optimal packing configurations for inventory during put away, enhancing operational efficiency. (LPN packing advisor)
  • Users can now approve physical inventory adjustments in bulk using a spreadsheet, streamlining the review and approval process for inventory adjustments. (Approve physical inventory counts using a spreadsheet)
  • Dynamic locator creation allows users to generate valid storage locations on the fly during transactions, enhancing flexibility in warehouse operations. (Use dynamic locator creation)
  • Users can now perform item translation for lot-controlled items, allowing reclassification of inventory while maintaining lot traceability. (Perform item translate for lot control items)
  • The Generate Changed Receipt Advice feature allows users to communicate purchase order quantity changes to integrated WMS or 3PL systems after receiving shipments. (Communicate additional purchase order changes to a WMS or 3PL using generate changed receipt advice)
  • Organizations can now receive additional electronic fiscal documents through Oracle Collaboration Messaging, including NFS-e, NFCom, and NF3-e, enhancing compliance for Brazilian operations. (Receive Brazil electronic fiscal invoices for services and utilities)
  • The default cost organization selected on the Cost Accounting landing page is now carried forward to various Cost Accounting and Cost Planning pages, improving usability. (Default cost organization across Cost Accounting pages)

What's Changed

  • Standard costing can now process transfer receipts and sales order issues even when there are unresolved negative inventory layers, allowing for continued transaction processing. (Process standard cost transactions despite unresolved negative inventory)
  • The mobile cycle count entry now allows users to view the current on-hand quantity while entering counts, helping validate inventory conditions. (View on-hand quantity during cycle count entry on a mobile device)
  • The mobile Receive Goods flow now makes the Order Number field optional and allows users to exclude receipt lines easily, streamlining the receiving process. (Receive goods using a mobile device using an optimized flow)

Deprecations, Retirements and Replacements

None identified in this release.
