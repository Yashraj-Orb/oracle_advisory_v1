Executive Summary

In the latest 26D release for Order Management, several significant features have been added to enhance order processing and management. Key highlights include the introduction of AI agent activity audits, which provide a framework for tracking changes on sales orders, and asset-based ordering, allowing organizations to manage orders based on existing customer assets. Additionally, enhancements such as the Sales Order Command Center now support returns and cancellations for complex product types, improving decision-making through AI-driven recommendations. Customers are advised to review their integrations and configurations due to important changes and deprecations, including the removal of certain web service operations and the need to migrate to new features before their target removal dates.

What's New

  • AI agent activity audit for sales orders introduces a framework to track AI-driven actions on sales orders, accessible from the Agent Actions tab. (AI agent activity audit for sales orders)
  • Asset-based ordering allows organizations to create orders referencing existing customer assets, supporting operations like amending and renewing subscriptions. (Asset-based ordering)
  • Users can now create and process coverage and subscription items within pick-to-order models, enhancing product offerings with optional warranties. (Create and process coverages and subscriptions within pick-to-order models)
  • Minimum remaining shelf life enforcement during order fulfillment improves compliance and customer satisfaction by requiring shelf-life rules. (Enforce minimum remaining shelf life in order fulfillment)
  • Recommended Product Configurations provide suggestions based on historical behavior, speeding up option selection in the Configurator Runtime UI. (Recommended product configurations)
  • The Sales Order Command Center now supports returns and cancellations for complex product types, leveraging AI recommendations for faster issue resolution. (Sales Order Command Center)
  • The Order Import Exceptions interface has been enhanced for better visibility and efficiency in handling failed sales order imports. (Import exceptions page)
  • Sales orders created with classic configured models can now be returned or copied using redesigned Redwood sales order pages. (Return and copy support for classic configured model sales orders)
  • Integration improvements between Inventory Management and Order Management enhance processing of transfer orders, supporting high transaction volumes. (TO-OM OutBound: inventory to change integration to stage transfer orders in order management interface table)
  • The redesigned parameters page for managing order management parameters offers a modern setup experience with improved search functionality. (Manage order management parameters)
  • The Configurator Runtime UI Designer allows customization of the configuration experience, enhancing navigation for sales-focused views. (Configurator runtime designer)
  • New configurator runtime capabilities support decimal quantities, improving order accuracy for products sold in fractional units. (Configurator runtime enhancements)
  • Users can create custom business object queries for data extracts, enabling faster and more efficient data extraction jobs. (Support for user-defined queries in data extracts)

What's Changed

  • The Sales Order Command Center now includes enhanced support for returns and cancellations, improving decision-making processes. (Sales Order Command Center)
  • The Order Import Exceptions interface now allows for self-service actions such as resubmission and deletion of source orders, enhancing user efficiency. (Import exceptions page)
  • The parameters management page has been modernized to improve the setup experience while retaining existing functionalities. (Manage order management parameters)
  • The Configurator Runtime now supports decimal quantities, enhancing order accuracy for fractional unit sales. (Configurator runtime enhancements)

Deprecations, Retirements and Replacements

  • The Get Order Details operation of the Order Information Service web service is removed in 27A, replaced by the Get One Sales Order action of the Sales Orders for Order Hub REST API. (IMPORTANT Actions and Considerations)
  • Planning for Orchestration Processes is no longer available starting in 26D. (IMPORTANT Actions and Considerations)
  • The Available Supplies REST resource is replaced by the Global Order Promises REST resource in 26A. (IMPORTANT Actions and Considerations)
  • The Purge Recent Objects scheduled process is replaced by the Delete Nontransactional Entities from Closed Sales Orders and Fulfillment Lines scheduled process in 25D. (IMPORTANT Actions and Considerations)
  • RequestHold and ReleaseHold operations in the Receive Order Request SOAP service are replaced by Apply Hold and Release Hold actions in the Sales Orders for Order Hub REST resource in 27A. (IMPORTANT Actions and Considerations)
