Covers: Warehouse Management 26D
Generated: 2026-10-20 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release of Warehouse Management brings a host of new features and enhancements aimed at improving usability and operational efficiency. Key updates include the introduction of a 3D warehouse inventory visualizer, expanded Redwood screens for better navigation, and enhanced reporting capabilities that allow for detailed audit trails of report usage. Additionally, significant enhancements to task-based putaway and mobile transactions streamline operations further. Clients should be aware of important actions required, including transitioning from SOAP to REST API integrations for FedEx and UPS, as well as migrating attachments to customer-hosted object storage. Deprecations include the SSH-based RF and.XLS format, which will be phased out in favor of Redwood Mobile WMS and.XLSX format, respectively.

What's New

  • Warehouse Management introduces a 3D warehouse inventory visualizer, allowing users to interactively view inventory and operational conditions in 2D and 3D formats. (3D warehouse inventory visualizer)
  • The Redwood Desktop experience has been expanded with new screens, including Clock View and Dashboard View Gen 2, enhancing navigation and usability. (Expanded Redwood experience for desktop)
  • A new report execution audit dataset provides visibility into Web Report usage, capturing details such as who ran reports and their execution status. (Web Report usage visibility)
  • The User Defined Mobile Designer allows the creation of user-defined mobile workflows in Redwood Mobile, enabling tailored mobile flows without new standard screens. (Redwood Mobile: introduce user configurable screens)
  • The Warehouse Execution Command Center is introduced as an AI-powered workspace for warehouse supervisors, focusing on outbound transactions and providing actionable insights. (AI Agentic App: Warehouse Execution Command Center)
  • A new prebuilt integration for inventory reconciliation using file-based processing allows WMS to fetch ERP on-hand and serial number information for serial-tracked items. (New prebuilt integration for inventory reconciliation using file-based processing)

What's Changed

  • The Mobile Load OBLPN transaction now honors the facility parameter ASSIGN_NEWLOAD_AT_CLOSE, preventing closure of loads with unassigned OBLPNs. (Expand mobile Load LPN transaction to honor load related facility parameters)
  • Administrators can now control access to the 'Launch Mobile App' link from the Desktop UI, allowing for restrictions based on group-level configurations. (Restrict launch mobile app access from desktop)

Deprecations, Retirements and Replacements

  • SSH-based RF will be deprecated for new customers starting January 2026, replaced by Redwood Mobile WMS, with existing support until January 2027. (IMPORTANT Actions and Considerations)
  • Support for.XLS format will be deprecated in 26D, customers should use.XLSX instead. (IMPORTANT Actions and Considerations)
  • Warehouse Management: The Legacy Designer is planned for deprecation in a future release. (Next Gen Label Designer)

Action Required

  • Migrate to REST-based carrier integrations for FedEx and UPS to comply with the upcoming deprecation of SOAP integrations. (IMPORTANT Actions and Considerations)
  • Follow instructions to migrate attachments to OCI Object Store to ensure continued access and compliance with new storage requirements. (IMPORTANT Actions and Considerations)
  • Switch from.XLS to.XLSX format to avoid issues with deprecated file formats in future releases. (IMPORTANT Actions and Considerations)
  • Prepare for the retirement of SSH-based RF by transitioning to Redwood Mobile WMS before January 2026. (IMPORTANT Actions and Considerations)
  • Report any issues with.XLS format before the 26D release, as these will not be handled post-release. (IMPORTANT Actions and Considerations)
