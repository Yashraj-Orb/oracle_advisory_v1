Executive Summary

In the 26D release for Procurement, significant enhancements have been made across the Procurement and Self Service Procurement modules. Notably, Supply Chain Orchestration now supports intra-organizational material transfers, allowing for better sourcing and fulfillment flexibility. Additionally, users can collaborate on procurement documents via Microsoft Teams, streamlining communication. Other improvements include enhanced lifecycle management for intake requests and new features for managing procurement contracts. Customers should review new features and opt in where necessary, as some features require specific actions to enable them.
