SCM · Global Trade Management: Release digest

Covers: Global Trade Management 26C
Generated: 2026-10-20 · Source: Oracle Cloud Readiness

Executive Summary

In the 26C release of Global Trade Management, several key features have been introduced to enhance compliance and operational efficiency. The restricted party screening module now allows users to designate parties as trusted or prohibited, improving screening control. Additionally, trade incentive programs have been enhanced with new configurations for physical inventory tracking and streamlined customs reporting. Notably, the 'Split Line for Penalty Reporting' action is deprecated, replaced by the 'Apply Tariff Unstacking Rules' action, necessitating updates to existing configurations. Customers should also be aware of new automation capabilities and enhancements to user interfaces, particularly with the integration of Redwood design elements.

What's New

  • The Restricted Party Screening module now allows parties to be designated as either trusted or prohibited, enhancing control over screening processes. (Set Trusted or Prohibited Party for Restricted Party Screening)
  • Physical inventory tracking is now available within Trade Incentive Programs, allowing for better management of inventory in Foreign Trade Zones. (Physical Inventory Tracking Available in Trade Incentive Programs)
  • The GTM Product Classification Assistant automates product classification for global trade compliance using AI, proposing harmonized codes based on item data. (GTM Product Classification Assistant)
  • OAuth 2.0 authentication can now be used for BI Publisher SOAP report services, enhancing security by replacing embedded user credentials with bearer-token authentication. (OAuth Authentication for BI Publisher SOAP Report Services)
  • A new REST utility action 'addDocuments' allows linking a single document to multiple objects in one action, streamlining document management. (REST API Custom Action to Add/Link a Document to Multiple Objects)

What's Changed

  • The Enhanced Workbench Inline Edit now always displays the External ID (XID) instead of allowing users to switch to the Global Identifier (GID). (Inline Edit Always Shows External ID (XID))
  • The workbench for Trade Incentive Programs has been enhanced to support new business objects and saved queries for improved visibility. (Enhanced Workbench Improvements for Trade Incentive Programs)

Deprecations, Retirements and Replacements

  • The 'Split Line for Penalty Reporting' action is deprecated and will return an error if executed; it is replaced by the 'Apply Tariff Unstacking Rules' action. (Deprecate Split Line For Penalty Reporting)
  • Basic authentication for BI Publisher SOAP web services is deprecated, requiring users to transition to OAuth-based authentication. (Deprecate Basic Auth for BIP SOAP Web Service)
  • Global Trade Management: The existing Split Line for Penalty Reporting action is deprecated; use the Apply Tariff Unstacking Rules action instead. (Enhanced Support for Penalty Codes and Penalty Exemption Codes)

Action Required

  • Transition to the 'Apply Tariff Unstacking Rules' action as the 'Split Line for Penalty Reporting' action is deprecated and will no longer function. (Deprecate Split Line For Penalty Reporting)
  • Review existing BI Publisher SOAP integrations and update report configurations to use 'BI Publisher SOAP with OAuth'. (Deprecate Basic Auth for BIP SOAP Web Service)
