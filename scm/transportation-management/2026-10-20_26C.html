Covers: Transportation Management 26C

Executive Summary

The 26C release of Transportation Management brings a host of new features and enhancements aimed at improving user experience and operational efficiency. Key additions include the AI Agent Studio with pre-seeded business objects, which simplifies the development of AI agents, and enhancements to the Redwood user interface, providing a more cohesive look and feel. Additionally, new functionalities such as the ability to manage dock scheduling and shipment changes through AI agents are introduced, along with improvements in REST services for better integration and data handling. Customers should be aware of the deprecation of basic authentication for BI Publisher SOAP services, requiring a transition to OAuth for enhanced security.

What's New

  • AI Agent Studio now includes thirty pre-seeded OTM/GTM business objects, facilitating easier AI agent development. (AI Agent Studio - Seeded Business Objects)
  • A new slash command feature allows users to quickly insert reusable AI prompt templates in chat inputs, enhancing workflow efficiency. (Slash Command for Prompt Selection)
  • The Redwood user interface has been expanded with additional UIs and features, including 39 Profile Managers and 8 Dynamic Managers. (Try the New Redwood Experience)
  • The Enhanced Workbench now displays the External ID (XID) consistently during inline edits, simplifying user experience. (Inline Edit Always Shows External ID (XID))
  • New logic configuration allows updates in Workbench detail tables to be processed as a single transaction, reducing notifications and processing. (Single Transaction Option for Workbench Inline Editing and Mass Updates)
  • REST services now support updates to reference numbers based on update flags, aligning behavior with XML APIs. (Honor Update Flag For REST RefNum Updates)
  • The Export API now supports delete operations for Tender Collaboration tables, enhancing data synchronization capabilities. (Export API - Delete Supported For Tender Collab Tables)
  • New AI agents for dock scheduling and shipment changes enable management of transportation activities through natural language requests. (AI Agent: Dock Scheduling Assistant; AI Agent: Shipment Change Assistant)
  • The Multi-Day Calendar Override feature allows users to define start and end dates for calendar overrides, enhancing scheduling flexibility. (Multi-Day Calendar Overrides)
  • New REST-enabled actions for Open Tender activities streamline automation of tender workflows, improving operational efficiency. (REST Enable Actions for Open Tender - Spot Bid Tender and Broadcast Tender)

What's Changed

  • The Enhanced Workbench Inline Edit now always shows the External ID (XID), removing the option to switch to the Global Identifier (GID). (Inline Edit Always Shows External ID (XID))
  • The Use Improved Split Order Movement Action feature requires users to opt in to take advantage of improved logic, transitioning to a new method. (Use Improved Split Order Movement Action)
  • The Suppress Error When No REST RIQ Results Found feature allows REST inquiries to return a 200 status code instead of a 500 error when no results are found, but requires user opt-in. (Suppress Error When No REST RIQ Results Found)

Deprecations, Retirements and Replacements

  • Basic authentication for BI Publisher SOAP Web Service will be deprecated, requiring OAuth-based authentication instead. (Deprecate Basic Auth for BIP SOAP Web Service)
  • Transportation Management: The Logic Configuration Parameter SHOW XID IN INLINE EDIT is no longer considered and will be removed in a future release. (Inline Edit Always Shows External ID (XID))
  • Transportation Management: Replaces property glog.business.shipmentactual.syncWithOrderOnCountIncrease. (SMD Sync With Order On SSU Count Increase)

Action Required

  • Users must opt in to the Use Improved Split Order Movement Action feature to utilize the new logic. (Use Improved Split Order Movement Action)
  • Users must opt in to the Suppress Error When No REST RIQ Results Found feature to change the default error handling behavior. (Suppress Error When No REST RIQ Results Found)
  • Users must opt in to the Fetch All Shipment Tracking Events feature to retrieve all tracking events matched via LEGACY SHIPMENT MATCHING. (Fetch All Shipment Tracking Events)
  • Users must opt in to the SMD Sync With Order On SSU Count Increase feature to maintain accurate data between shipments and orders. (SMD Sync With Order On SSU Count Increase)
